# Контроль созревания партий сыра

Программа КТ3 регистрирует новую партию, формирует список работ на дату и подбирает камеры по температуре и влажности. JDK 21, сборка через javac. Библиотека Gson 2.14.0 для JSON и её лицензия находятся в lib/.

## Сборка и запуск

Выполните в PowerShell из папки src/java:

```powershell
javac --release 21 -encoding UTF-8 -cp "lib/*" -d out *.java
java -cp "out;lib/*" WorklistDemo
java -cp "out;lib/*" PracticeChecks
```

В Linux и macOS разделитель путей в аргументе -cp для java — двоеточие. Входные файлы по умолчанию берутся из текущей папки.

## Пример

demo.json содержит три партии, три камеры, справочник видов операций, пять запланированных работ, замер и запись контроля качества. new_batch.json содержит новую партию B4. На 1 ноября 2026 года вывод совпадает с КТ2:

```text
Зарегистрирована партия: B4

Работы на 2026-11-01
W1: просрочено
W2: сегодня

Подходящие камеры для ожидающих партий
B2: C1, C3
B3: C2
B4: подходящих камер нет
```

Для другой даты и сохранения всех шести наборов данных с добавленной партией:

```powershell
java -cp "out;lib/*" WorklistDemo --data demo.json --batch new_batch.json --date 2026-11-02 --save result.json
```

При повторной регистрации B4 в result.json программа выдаёт ошибку дублирования. Чтобы запустить только список работ, передайте дату позиционным аргументом, например `java -cp "out;lib/*" WorklistDemo 2026-11-01`.

## Связь с КТ2

| Операция Python | Метод Java |
|---|---|
| register_batch | BatchRegistry.registerBatch |
| build_worklist | WorkSchedule.buildWorklist |
| select_chambers | BatchRegistry.selectChambers и Batch.accepts |

WorkSchedule просматривает работы один раз, O(n). BatchRegistry просматривает все партии и для каждой ожидающей проверяет все камеры. Для n партий и m камер верхняя оценка O(n + n·m). Оба алгоритма сохраняют порядок входных записей.

ClimateReading объединяет текущие показания камеры и исторический замер. Measurement и QualityCheck наследуют общие поля BatchEvent и переопределяют summary(). PracticeData читает JSON, проверяет идентификаторы и ссылки между сущностями, передаёт данные предметным классам и сохраняет результат. PracticeChecks проверяет операции, границы диапазонов, обработку дублей, обе реализации интерфейса и сохранение.
