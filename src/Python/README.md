# КТ2 — модели и процедурная программа

Тема: «Производство твёрдых сыров с длительной выдержкой».
Процесс: «Организация и контроль процесса созревания партии твёрдого сыра».

## Запуск

Целевая версия проекта — Python 3.13; код использует стандартную библиотеку и дополнительно проверен на доступном Python 3.12.14. Внешних зависимостей нет, requirements.txt не требуется.

Из папки src:

```powershell
python main.py
python test_checks.py
```

Из корня распакованного архива: `python src/main.py`. Пути к входным файлам по умолчанию определяются относительно main.py, поэтому рабочая папка не влияет на запуск.

Вход: demo.json содержит шесть массивов сущностей; new_batch.json — новую карточку B4 для регистрации. Данные учебные: температурные диапазоны и сроки не являются технологической инструкцией для производства.

Ожидаемый вывод:

```text
Зарегистрирована партия: B4

Работы на 2026-11-01
W1: просрочено
W2: сегодня

Подходящие камеры для ожидающих партий
B2: C1, C3
B3: C2
B4: подходящих камер нет
```

W3 ещё не наступила, W4 выполнена, W5 ещё не наступила. Для B2 подходят две камеры, для B3 одна, для B4 — ни одной. Список кандидатов сохраняет порядок камер во входном JSON.

Свои данные и сохранение результата:

```powershell
python main.py --data demo.json --batch new_batch.json --date 2026-11-02 --save result.json
```

Без --save входные файлы не изменяются. При повторной регистрации B4 в уже сохранённом result.json программа сообщит о дублировании id — это ожидаемое поведение. Для новой регистрации подготовьте карточку с другим id.


## Границы версии

- Подбор проверяет только температуру и влажность и не назначает камеру автоматически. Вместимость, совместимость сортов и резервирование мест не моделируются. Окончательное размещение решает сотрудник.
- Исторические измерения и решения контроля качества присутствуют в JSON как данные процесса; их внесение и оценка качества остаются ручными, отдельного CRUD-интерфейса для них нет.
- Все функции получают данные через параметры; собственных классов и глобальных изменяемых коллекций нет. СУБД на данном этапе не подключается.
